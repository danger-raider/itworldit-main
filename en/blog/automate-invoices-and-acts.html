How to stop creating invoices and completion acts manually when you have more than 3 clients

Document workflow automation without a corporate monster: templates, spreadsheets, CRM, email and a few smart rules.

When you have one or two clients, manually creating invoices, completion acts and emails feels manageable. But once the number of clients grows, documents become a quiet bureaucratic hydra: one template, another date, a third file, a fourth email and then “where did we save it?”.

Document workflow automation does not have to mean an expensive ERP system. Often, a clean setup is enough: document template, spreadsheet or CRM, PDF generation, email sending, storage in the right folder and a simple log of what happened.

What can be automated

  • creating invoices, completion acts, contracts or commercial proposals;
  • inserting client name, amount, date and document number;
  • saving a PDF to the correct folder;
  • sending the document to the client by email or messenger;
  • reminders about unpaid invoices;
  • logging statuses in Google Sheets, CRM or an internal system.

A minimal workflow

The simplest version looks like this: you fill in a row in a spreadsheet or submit a form, and the system creates a document, names the file using a clear pattern, sends it to the client and records the result.

  1. Data source: Google Sheets, CRM, form or Web UI.
  2. Template: a document with fields to fill in.
  3. Generation: PDF or DOCX.
  4. Sending: email, Telegram, Viber or another channel.
  5. Archive: drive folder with clean file names.
  6. Log: date, client, amount, status and document link.

Where no-code fits, and where code is better

Make or Zapier are good for simple flows like form → spreadsheet → email. But if you need complex rules, unique file names, PDF processing, specific APIs or local storage, a small custom module is usually a better fit.

The main point is not the tool. The main point is process stability. Automation should not create a new kind of chaos. It should remove the old one.

Practical takeaway: if you regularly copy the same data from a spreadsheet into a document and then into an email, it is already a perfect candidate for automation.
